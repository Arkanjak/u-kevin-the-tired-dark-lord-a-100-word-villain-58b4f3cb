A program that writes a 100-word monologue for a fantasy villain who is secretly just very tired — a gate-keeper of three hundred years, a curse laid by clerical error, a grand scheme still on for tomorrow, perhaps. The tiredness lives in the pauses and the kettle, never in a plain announcement.

## Run it

```sh
node main.ts
```

Writes the monologue to `/output/entry.txt` (100 words, 522 characters, inside the 1–600 character gate).
